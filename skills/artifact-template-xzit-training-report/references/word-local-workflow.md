# 本地Word与科技文献检索实训

## 工具选择

优先查找已连接的Word文档会话及其支持能力。无连接不等于本机Word不可用。Windows有Microsoft Word时，可以用其正规COM文档对象模型对本次生成的副本更新目录、另存和导出PDF；需要UI时再使用可用Computer Use技能。不得用UI在终端中输入命令，不混用PowerShell UI Automation与Computer Use，不操作与报告无关的用户文档。

`refresh_fields.ps1`仅新建一个隐藏Word实例，只读打开输入，在不同路径另存DOCX和PDF，更新目录和页码后只关闭自己创建的文档/实例。若用户要求前台编辑或查看完成稿，再用Word打开成品。用户明确要求Word时，不因通用渲染脚本缺少LibreOffice而停止；记录失败原因，以Word导出PDF、Poppler渲染PNG逐页检查。无需为一次报告盲目安装新插件。

## 本课程内容组织

当用户明确要“科技文献检索与写作规范”实训报告时，应兼顾检索训练与主题综述：主题拆分、平台与实际检索式、筛选条件、来源与版本核验、证据组织、专题分析和写作反思。普通主题报告不强制采用这一结构。

只将有记录的检索词、平台、日期、数量描述为已执行；拟用布尔检索式标明为可复用策略。已有专题集合不是系统综述，不编造命中量、筛选流图或实验。主题文献实际引用不少于用户要求的篇数，每条正文与文后对应；最低篇数和语种比例由当前任务决定。

## 排版中的具体检查

- 身份留空须得到用户明确选择；`identity_mode: blank`允许空字符串，原有横线栏位保留，其他情况下仍拒绝缺失身份。
- 英文题目多行时保持22pt Arial，优先调整封面无内容空白段；不缩小字号。日期不得被挤到单独一页。
- 多个相近小节可经内容判断合并，保持目录三级上限和既定字号；不能为强塞一页而删实质内容或缩小字号。目录多页本身允许，避免仅末条溢出一页。
- 短比较表可以整表同页，保持三线表、10.5pt宋体和单倍；长表跨页则重复表头并逐页加右上续表标识。列宽可通过`widths_cm`设置，总宽不超过内容区。
- 图片段落与下题注相连。数学公式用可编辑OMML；居中/右对齐制表位可使公式居中、编号靠右。变量定义逐一对应，换行时按破折号后文字对齐。化学式下标可用run级subscript，不能改动正文规定字号。
- 源封面空段的`firstLineChars`等直接属性可能高于样式；将课程名等填入原空段时清理冲突缩进，不能只设firstLine=0就认为完成。
- 某些图像展示会复用相同页眉区域；怀疑页眉丢失时核对PDF实际文字位置、颜色与PNG像素，再决定是否改Word，避免误改正常文稿。

## 最终质量门

保留范本的DOC原件转换后带Word 2003兼容级别11，并不意味着报告必须按该旧格式保存。现代Word DOCX生成默认使用兼容级别15，保持原页边距、字体和段落规则。若保存时出现“公式将转换为图像”等兼容性提示，取消该保存，另存现代DOCX并检查原生OMML、链接和重新分页；不默认点继续。用户明确要求旧版兼容时按其要求处理并说明实际损失。兼容级别变化作为技术修复记录，不能伪称源模板本身使用15。

上标及跳转检查：XML应有`w:vertAlign= superscript`与有效的`w:hyperlink/@w:anchor`，锚点对应文后唯一书签。Word刷新后再次检查；DOI的完整文本必须与关系目标一致，防止拼写检查标记把链接截断。正文与TOC的超链接内文字也应计入字体检查，不能只检查直接run。

编辑标记：不把全局“显示所有”关闭等同于所有单项标记都关闭。Word还可能始终显示段落标记。若COM设置未反映到窗口，不连续盲目重复设置；用Computer Use观察实际“显示”选项并取消对应复选框。UI处于锁屏时停止UI操作，待用户解锁后重选窗口。保留用户未保存的内容，先保存本次副本，不关闭或改动无关文档。

写作检查按段进行，优先删除没有新信息的解释和自我评价。实训报告可写真实的检索方法、阅读记录和遇到的问题；技术段落直接讨论材料、条件和结果。修辞上少用对仗、排比及“并非…而是…”反复转折，不以捏造实验或第一人称经历来追求自然表达。任何检测工具都不能证明文字“没有AI风格”，交付前应实际阅读全文。

机器格式通过、引文数量/对应通过、来源人工核验、Word字段已更新、全部最终页渲染已看，五者分别记录。`ready_for_submission=false`是检查脚本对机器能力的保守声明，可在任务工作记录中另行写明人工复核与用户自填项目；不能修改脚本强行将所有报告标成可提交。实际报告不自动上传GitHub；只有获授权的技能更新可以同步。

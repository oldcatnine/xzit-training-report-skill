# 生成执行契约

原件 `assets/reference.docx` 不可变，哈希见 `source-provenance.json`。新报告克隆校徽、封面表格、页面几何、分节、页眉页脚；移除生成副本的说明框、样例、错误目录。字体/标题段距按明确说明修正。

槽位：中英题目、五项身份与日期、中英摘要/关键词、三级目录、正文1—4级标题、图表公式、结论、致谢、文献、可选附录。原例矿浆和成本等不能作为新研究数据。复杂公式采用可编辑OMML及右端编号；跨页表逐页核验。

每次工作记录包含：输入与哈希、规则版本及ID、槽位映射、来源证据表、显式偏离及依据、机器检查路径、字段更新时间、逐页渲染观察、待核项。只有“通过/失败/待核”三类状态，待核不能算通过。

# 徐州工程学院实训报告格式整理以及生成skill

格式是验收重点。先读[完整格式规则](references/format-requirements.md)，再读`artifact-template.json`。不可修改`assets/reference.docx`。优先级：当前用户明确指令 > 范本明确说明 > 范本实际属性 > 工具默认值。记录冲突依据，不照抄蓝色说明框、示例数据、占位符及错误书签。

## 生成与核验

1. 确定本次是综述、实训过程还是含真实实验/建模的报告；读取新文献、任务书及身份信息。读[文献工作流](references/literature-workflow.md)，建立论断—来源—页码—条件的证据表。未知身份可生成明确待补草稿，不能编造实训经历、数据、精度或参考文献。
2. 按任务安排中英文题目、摘要、关键词、目录、正文、结论、致谢、文献及可选附录；不把样例篇幅/数量当成学校要求。任务非光伏时仅使用通用格式，不强行套用光伏章节。
3. 加载[@documents](plugin://documents@openai-primary-runtime)的模板工作流，克隆原件到新路径，保留校徽、页面、封面几何及页眉页脚。也可用`python scripts/build_report.py input.json report.docx`起稿，见[input-schema](references/input-schema.md)。复杂公式、续表、交叉引用须由文档工具完成，不得因脚本限制省略内容。原件不覆盖。
4. 按[执行契约](references/artifact-contract.md)记录规则版本、输入哈希、槽位、偏离依据和检查结果。工具细节不进入报告正文。
5. 运行`python scripts/audit_docx.py report.docx --output audit.json`，修复失败项。检查的是实际生效格式；未知角色必须映射或人工核验，不能只看样式定义。机器通过不等于最终可提交。
6. 用Word/LibreOffice更新目录、页码、交叉引用；Windows可用`scripts/refresh_fields.ps1`另存副本并导出PDF。修复“错误!未定义书签”，不能交付未更新的目录占位为终稿。
7. 渲染逐页看封面、空白页、罗马/阿拉伯页码起点、三级目录、标题分页、续表表头、题注位置、公式编号和文献。检查字体实际可用；修复后复核受影响页及连锁分页。
8. 交付DOCX、可用时的PDF、证据表和检查记录，明确草稿/终稿与剩余待核项。

本机Word操作与课程实训模式见[本地Word工作流](references/word-local-workflow.md)。用户允许身份留空时使用`identity_mode: blank`，五项身份均显式传空字符串，保留原栏位供手填；不写“待补”占位或虚构资料。课程名、主题和参考篇数是本次任务条件，不能推定为全校永久统一要求。

有最低参考文献数量要求时另运行`python scripts/audit_citations.py report.docx --min-references N --output citations.json`，检查实际引用、连续编号、首次出现顺序和未引用条目；N由当前任务决定，不固定为10。此脚本不验证文献是否真实或论断是否得到支持，必须结合全文证据复核。

## 只检查现有报告

先读全部规则并在副本上工作，列位置、错误和修复依据。保留作者结论、公式对象、链接、图片。对非`XZIT*`样式建立角色映射，不能跳过未知正文；题注不能误当正文。格式任务不擅自重写科研结论。

## 易错约束

- 正文引文采用右上角上标，并超链接到文后对应编号；文后编号保持正常基线，DOI链接指向完整出版标识。生成器自动处理，现有稿可运行`python scripts/scholarly_format.py input.docx output.docx`。跨run和Word拼写标记的DOI必须核对完整链接，不能只确认链接数量。
- 本范本三线表可见线宽为1.5pt（OOXML sz=12），上边线、表头下横线和下边线均按此值；无左右竖线及其他内部横线。封面身份栏不套用正文三线表处理。
- 标题/题注前出现黑方点，先区分真实项目符号和非打印的段落分页标记；后者关闭Word编辑标记显示，不删除与下段同页、段中不分页或章前分页属性。
- 写作使用具体材料、工况、数据和比较结果。删改反复的“本报告将”“首先其次最后”“意义重大”等套话，以及空泛排比和把普通分析写成口号的句子；不靠禁词表机械替换。保留实验条件、引用和不确定性，不编造个人经历。

- 四级标题允许，目录只到三级；章及结尾部分新页起。前置罗马页码，正文从阿拉伯1开始、其后连续。
- 小四12pt、五号10.5pt；黑体小二18pt、小三15pt、四号14pt、二号22pt、初号42pt；0.5行不等于固定6pt。
- 正式英文引用用原题；数值明确来自文献、实测还是本次计算，不能混写。
- 未声明的字数、篇数、关键词数和GB/T版本不虚构为硬性校规。
- 本次调用不自动授权未来发布报告或上传身份/论文全文。GitHub参考与许可判断见[调研](references/github-research.md)。
